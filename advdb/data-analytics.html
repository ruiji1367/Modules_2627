OLAP vs. OLTP Systems

Two very different jobs: running the business day-to-day, versus analyzing it after the fact.

SystemWhat it's forExample
OLTP
Online Transaction Processing		 Operational, day-to-day transaction management — fast, simple reads/writes on current data. An ATM withdrawal
OLAP

MODULE 3

Advanced T-SQL Aggregation & Cross-Tabulation

Three ways to extend GROUP BY for richer analytical reporting.

ROLLUP — hierarchical aggregation

Extends GROUP BY to generate subtotal and grand-total rows, following a defined hierarchy of the grouped columns (here, Region → City).

SELECT
    Region,
    City,
    SUM(SalesAmount) AS TotalSales
FROM Sales
GROUP BY ROLLUP(Region, City);

ROLLUP produces NULL in a column wherever it's showing a subtotal or grand total for that level. COALESCE() replaces those NULLs with a readable label:

SELECT
    COALESCE(Region, 'All Regions') AS Region,
    COALESCE(City, 'All Cities') AS City,
    SUM(SalesAmount) AS TotalSales
FROM Sales
GROUP BY ROLLUP(Region, City);

CUBE — multi-dimensional aggregation

Generates subtotals for every possible combination of the grouped columns — not just a hierarchy like ROLLUP, but every cross-section.

SELECT
    Region,
    ProductCategory,
    SUM(SalesAmount) AS TotalSales
FROM Sales
GROUP BY CUBE(Region, ProductCategory);

PIVOT — cross-tabulation

Rotates distinct row values into separate columns, turning long-format data into a cross-tabulation report.

SELECT ProductCategory, [2023], [2024], [2025]
FROM
(
    SELECT ProductCategory, SalesYear, SalesAmount
    FROM Sales
) AS SourceTable
PIVOT
(
    SUM(SalesAmount)
    FOR SalesYear IN ([2023], [2024], [2025])
) AS PivotTable;
