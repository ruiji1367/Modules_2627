Where does your data go when the program closes?

A student builds a grade tracker in C#. After closing it, every grade is gone.

Variables live in memory and disappear when the program ends. To keep data, the program must write it to a file, and read it back later.

Streams

A stream is a source that provides a sequence of bytes: a file, an I/O device, an interprocess pipe, or a TCP/IP socket.

Output stream

Where data is written: a file, printer, or remote server.

Input stream

Where data is read from and assigned to variables in the program.

In C#, add using System.IO;. All files are byte-oriented.

FileStream and FileMode

FileStream creates a byte-oriented stream attached to a file. FileMode says how to open it.
